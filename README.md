# AIQU Executive Majlis 2026

Microsite for the AIQU Executive Majlis, Financial Crime Compliance in the Age of AI. Tuesday, 24 November 2026, Dubai. Organised by Plexus Global.

Built with Vite, vanilla JavaScript and Tailwind CSS v4.

```bash
npm install
npm run dev
npm run build
```

Routes: /, /agenda, /why-join, /about, /contact (Netlify rewrite to index.html in netlify.toml).
Registration link and shared chrome: src/layout.js.
